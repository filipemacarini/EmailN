# EmailN

## Domain 

Um serviço para envio de email em lote. O objetivo é centralizar o envio dos emails, para que o sistema cliente não perca tempo enviando email a email.

**Features**
- Endpoint para envio dos emails em lote com os contatos.
- Endpoint para informar o status do lote enviado.
- Os emails enviados poderão ser personalizados por contato, com isso, informações do contato poderão estar no texto do email.
